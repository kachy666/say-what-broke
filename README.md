# say-what-broke

A single line of software error copy for the make.fun competition "Say What Actually Broke". The line tells the brutal truth — the file is not where you think it is — and points at the real culprit: your Downloads folder, where 400 files all called final_final_v2 are hiding it. It names the failure in plain words, tells you where to look next, and lands its joke in one read, the way a dialog a team would actually ship should.

> We couldn't find 'the file you definitely saved here' — it lives in Downloads, beside 400 files named final_final_v2.

The program in `main.py` checks the line against the competition rules (a single line, 1–200 characters, ending with a period) and writes it to `/output/entry.txt`.
